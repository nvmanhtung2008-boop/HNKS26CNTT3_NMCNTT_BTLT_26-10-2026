


# Quản lý GameZone
> **Lưu ý** tuyệt đối không tải lên hoặc commit file *`.env`* để tránh làm lộ thông tin.

## Cấu trúc thư mục
| Thư mục | Nội dung |
|:---| :---|
|data| Dữ liệu giao dịch|
|docs| Tài liệu dự án|
|media| Hình ảnh logo thương hiệu và nhận diện  |
|logs| Nhật ký hoạt động hệ thống|
|backup| Bản sao lưu định kỳ|

## Kiểm tra cấu trúc thư mục
Chạy lệnh sau ở thư mục gốc để xem cấu trúc toàn bộ:
```PowerShell
Get-Childitem -Recurse -Force
```
